FAQs

Everything you need to know about ChainedMac.

Can’t find what you’re looking for? See the download and setup options.

It arranges your open app windows into one horizontal strip. Move focus with the arrow shortcuts, widen or center the focused window, then restore the original positions when you’re done.

Use Shift + Left Arrow for the previous window and Shift + Right Arrow for the next. Restore positions with Control + Option + R on Mac or Control + Alt + R on Windows.

macOS requires this permission so ChainedMac can move and resize app windows. Turn it on in System Settings → Privacy & Security → Accessibility.

No account, cloud service, or telemetry is included. Your preferences stay on your device, and the browser preview uses sample windows only.

The Mac app supports macOS 13 or later on Apple silicon and Intel. A Windows x64 build is available for Windows 11 and Windows 10 LTSC or Enterprise.

The strip contains the movable windows that were open when you arranged it. If you open or close a window afterward, arrange again to refresh the strip.

Quit restores the window positions captured when you arranged the strip. If an app prevents a window from being restored, ChainedMac stays open so you can retry. A force quit or crash can bypass this cleanup.
